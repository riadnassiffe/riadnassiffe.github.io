Development of a Bifunctional Robot

    Ríad M. Nassiffe
  • Tags: 
  • Robotic, 
  • Arduino, 
  • Python

Add dynamic content to your GitHub profile through an intuitive plugin system.

This project began in 2021 with the proposal of creating an embedded system, specifically a robot, aimed at educational purposes and serving as a prototype for future research in embedded systems, real-time systems, and robotics. As planned, the project resulted in a robotic platform controlled by code written in Python that communicates via wireless technology.
