Desenvolvimento de um Robô bifuncional

    Ríad M. Nassiffe
  • Tags: 
  • Robótica, 
  • Arduino, 
  • Python

Sistema robótico para o ensino de programação e plataforma de tempo real.

Este projeto foi iniciado em 2021, que tinha como proposta a criação de um sistema embarcado, mais especificamente um robô, voltado para atender finalidades educacionais e que pode servir como protótipo para desenvolvimento de futuras pesquisas em sistemas embarcados, de tempo real e robótica. O projeto conforme previsto, gerou uma plataforma robótica controlado via Bluetooth.
